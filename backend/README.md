# Backend (Go + Beego v2)

REST API implementing [`docs/API_CONTRACT.md`](../docs/API_CONTRACT.md): email/password auth with JWT access tokens and
rotating refresh tokens (reuse detection), email verification, password reset, TOTP 2FA + recovery codes, WebAuthn
passkeys, admin endpoints, audit log, Swagger UI and a server-rendered admin UI.

The binary is **self-contained and CGO-free** (`modernc.org/sqlite`): swagger spec, Swagger UI, admin templates and
static files are embedded with `//go:embed`.

## Layout

```
main.go          entrypoint, version vars (ldflags), go:embed of swagger/ static/ views/
app/             composition: DB, container, Beego config, middleware chain, embedded static serving
config/          env config (+ prod safety check)
models/          Beego ORM entities
repositories/    persistence interfaces + ORM implementations
services/        business logic: auth, token, mfa, passkey, admin, audit, user, one-time tokens
mail/            Mailer interface: console + smtp, text/HTML templates
controllers/     thin Beego controllers (base controller has JSON/error helpers)
filters/         net/http middleware (CORS, CSP/security headers, rate limit, logging, recover) + Beego auth filters
routers/         router.go (swagger header + namespaces) and generated commentsRouter.go
dto/             request/response structs + validation
swagger/         generated swagger.json / swagger.yml (committed)
views/, static/  admin UI templates and assets (static/swagger-ui = local swagger-ui-dist)
```

## Run locally (SQLite)

```bash
cd backend
cp .env.example .env            # optional; every variable has a dev default
make run                        # http://localhost:8080 ; DB at data/app.db ; emails are logged to the console
```

* Health: `GET /healthz` -> `{"status":"ok","version":"dev"}`
* Swagger UI: <http://localhost:8080/swagger/> (spec: `/swagger/swagger.json`)
* Admin UI: <http://localhost:8080/admin-ui/> (set `ADMIN_EMAIL` / `ADMIN_PASSWORD` to seed an admin)

With `MAIL_DRIVER=console` verification/reset links are printed in the server log.
Set `REQUIRE_EMAIL_VERIFICATION=false` to skip verification in dev.

## Run with docker-compose (Postgres + Mailpit)

```bash
docker compose up --build       # from the repo root
```

API on :8080, Postgres :5432, Mailpit UI <http://localhost:8025> (SMTP :1025). A seeded admin
(`admin@example.com` / `change-me-please`) is created; override with `ADMIN_EMAIL`/`ADMIN_PASSWORD`.

## Make targets

`make run | build | test | lint | docs | tidy`. `make build` produces `bin/server` with `CGO_ENABLED=0`.

## Swagger / OpenAPI

Docs are generated by [bee](https://github.com/beego/bee) from the annotations on `routers/router.go` and the
controllers:

```bash
go install github.com/beego/bee/v2@latest
make docs      # = bee generate routers && bee generate docs
```

This rewrites `routers/commentsRouter.go` and `swagger/swagger.{json,yml}`; commit both. Output is deterministic, so CI can
check `git diff --exit-code -- swagger routers`. The spec is embedded in the binary and served at `/swagger/swagger.json`.

## Adding a new endpoint

1. Add a request/response struct to `dto/` (with `json` tags; request types implement `Validate()`).
2. Put the logic in a service method (`services/`), talking to repositories through their interfaces.
3. Add a controller method with annotations and a `@router` line:
   ```go
   // @Title Thing
   // @Security BearerAuth
   // @Param body body dto.ThingRequest true "..."
   // @Success 200 {object} dto.ThingResponse
   // @router /thing [post]
   func (c *MeController) Thing() {
       var req dto.ThingRequest
       if !c.Decode(&req) { return }
       res, err := c.C.Things.Do(c.ReqContext(), c.CurrentUser(), &req)
       if err != nil { c.Fail(err); return }
       c.OK(res)
   }
   ```
4. For a new controller, add `web.NSNamespace("/prefix", web.NSBefore(filters.Authenticate), web.NSInclude(&controllers.X{}))`
   to `routers/router.go`.
5. `make docs`, then add an integration test in `integration_test.go`.

Note: files/dirs starting with `_` or `.` are not embedded by `go:embed`; name template partials accordingly.

## Tests

`make test` runs service unit tests (password hashing, token rotation/reuse detection, TOTP, recovery codes, one-time
tokens), middleware tests and HTTP integration tests (`integration_test.go`: register/verify/login/refresh/logout,
forgot/reset, 2FA login, admin access control, CSP/CORS/swagger) against a temp SQLite DB.

## Security notes / limitations

* Strict CSP with per-request nonce on non-API responses; JSON API responses use `default-src 'none'`.
* Refresh tokens and one-time tokens are stored as SHA-256 hashes; reuse of a rotated refresh token revokes its family.
* WebAuthn ceremony sessions live in memory (`services.SessionStore`); use a shared store for multi-instance deployments.
* Rate limiter is in-memory per instance. Schema is created with `orm.RunSyncdb` (creates missing tables, does not alter
  existing ones) - add real migrations before changing models in production.
* `POST /me/change-password` does not revoke other sessions; `reset-password` and admin disable do.
